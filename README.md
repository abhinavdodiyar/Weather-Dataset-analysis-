
Weather Dataset Analysis Using Python

Project Description

This project analyses weather data using Python. It displays weather records, calculates temperature statistics, counts weather conditions, and creates bar charts.

Objectives

- Analyse weather data.
- Display the first five rows.
- Calculate temperature statistics.
- Count different weather types.
- Visualise weather data using graphs.

Technologies Used

- Python
- Pandas
- Matplotlib
- Google Colab

Dataset

Seattle Weather Dataset

Project Files

- Weather_Dataset_Analysis.ipynb - Python program
- weather.csv - Weather dataset
- Weather_Project_Screenshots.pdf - Program and output screenshots

Output

The program displays weather data, statistical summaries, and two bar charts.

Conclusion

This project demonstrates basic weather data analysis and visualisation using Python.
